# SSE та WebSocket через HTTP/1.1

Один приклад показує два способи обміну повідомленнями з браузером. Обери режим,
відкрий [сторінку демо](http://127.0.0.1:8082/) і подивись запити на вкладці Network.
Команди запуску виконуй із кореня репозиторію.
Обидва режими слухають порт 8082 на loopback. Перед перемиканням зупини сервер через Ctrl+C.

## SSE — події від сервера

```sh
dotnet run --project 15b_2011_HTTP1.1_REALTIME -- --sse
# В іншому терміналі
curl -iN http://127.0.0.1:8082/events
```

У тілі відповіді `text/event-stream` з інтервалом в одну секунду приходять три події.
У першої події два поля й порожній рядок наприкінці.

```text
id: 1
data: tick 1

```

[ServerSentEvents.cs](ServerSentEvents.cs) кодує кожну подію в UTF-8 і передає її
окремою HTTP-частиною (chunk). Порожній рядок завершує подію, а нульова частина завершує
HTTP-відповідь. Сторінка відкриває `EventSource("/events")` і показує кожну подію одразу.
Якщо зв’язок перерветься, браузер може відновити читання з останнього отриманого ID.
Для перевірки виконай `curl -iN -H 'Last-Event-ID: 2' http://127.0.0.1:8082/events` —
прийде лише `tick 3`. Після ID 3 сервер відповідає `204 No Content`.

## WebSocket — текст в обох напрямках

```sh
dotnet run --project 15b_2011_HTTP1.1_REALTIME -- --ws
```

Відкрий [сторінку демо](http://127.0.0.1:8082/). Браузер підключається до `/chat`,
надсилає «Привіт!» і показує відповідь. У Network відкрий запит `chat`: у Headers видно
`101 Switching Protocols`, у Messages — надісланий текст і його копію від сервера.

[WebSocketEcho.cs](WebSocketEcho.cs) обчислює `Sec-WebSocket-Accept` і переходить від
HTTP-заголовків до кадрів. Сервер знімає маску клієнта, збирає фрагменти текстового
повідомлення та повертає його одним кадром. Також відповідає на Ping і Close.
Ліміт тексту становить 4096 байтів UTF-8. Як і в інших демо HTTP/1, сервер обслуговує
одне з’єднання за раз і завершує читання після п’яти секунд без даних.

Формати обміну описано у [специфікації SSE](https://html.spec.whatwg.org/multipage/server-sent-events.html)
та [RFC 6455](https://www.rfc-editor.org/rfc/rfc6455).

```sh

```
